# 数据导入导出说明

本文档说明 IUQA 的本地数据边界、题库与考试规则的导入导出流程、个人数据备份方式，
以及各类错误提示的含义与处理办法。

---

## 1. 数据存放位置

| 数据 | 存放位置 | 是否可导出 |
|---|---|---|
| 考生档案（昵称、头像、考生编号） | IndexedDB `users` | ✅ 个人数据导出 |
| 考试记录（含试卷快照、答卷、成绩） | IndexedDB `examAttempts` | ✅ 个人数据导出 |
| 电子证件 | IndexedDB `certificates` | ✅ 个人数据导出 |
| 题库（内置 + 导入） | IndexedDB `questionBanks` | ✅ 题库导出 |
| 考试规则 | IndexedDB `examRules` | ✅ 规则导出 |
| 应用设置（启用题库、公告阅读、学习进度、管理模式） | IndexedDB `appSettings` | ✅ 个人数据导出 |
| 本地操作历史 | IndexedDB `auditEvents` | ✅ 个人数据导出 |
| 主题、侧边栏状态 | localStorage | ❌ 非关键 UI 偏好 |

> **localStorage 只承载主题等非关键 UI 偏好，不作为主要数据库。**

## 2. 题库导入

### 操作路径

「题库管理」页面 → 开启本地管理模式 → 「题库管理」标签页 → **导入题库 JSON**

### 两步流程（先校验，后应用）

```
选择文件
   │
   ├─► 解析 JSON ──失败──► 展示解析错误，现有题库不变
   │
   ├─► Zod 完整校验 ──失败──► 展示带字段路径的错误列表，现有题库不变
   │
   └─► 校验通过 ──► 展示题库摘要 + 提示项 ──► 点击「应用该题库」才写入数据库
```

**关键保证：校验未通过的题库不会写入数据库，当前正在使用的有效题库保持不变。**

校验通过后，界面会展示：

- 来源文件名、`bankId`、题目数量、分值合计
- 是否为**覆盖同 ID 题库**（会明确标注「将覆盖同 ID 题库」）
- 非阻断提示项（例如情景题分值不一致、题目未设标签）

### 导入后的行为

- 题库以 `source: "imported"` 写入，管理页面用「本地导入」徽章标注来源
- **自动加入启用列表**，无需手动勾选
- 写入一条 `bank_imported` 操作历史

### 校验错误示例

```
共 3 处错误，字段路径如下：
questions[3].answer.correctOptionIds[0]   正确答案引用了不存在的选项 ID：Z
questions[5].options                      选项 ID 重复：A
questions[8].answer                       单选题必须且只能有一个正确答案，当前为 2 个
```

完整的校验规则见 [题库编写指南](题库编写指南.md#6-全部校验规则)。

## 3. 题库导出

「题库管理」→ 对应题库卡片 → **导出 JSON**

- 导出内容为**导入时的原文**（`rawJson` 字段），逐字节一致，可用于往返验证
- 文件名为 `<bankId>.json`
- 内置题库同样可以导出，便于以此为模板编写新题库

### 恢复内置题库

「题库管理」→ **恢复内置题库** → 二次确认

- 把随应用分发的内置题库写回数据库，覆盖同 ID 的本地题库
- **用户导入的其他题库不会被删除**，但启用列表会被重置为全部内置题库
- 适用于题库被误改后快速回到已知可用状态

### 删除题库

「题库管理」→ 对应题库卡片 → **删除题库** → 二次确认

- 仅删除题库记录，**已参加过的考试记录不受影响**（试卷快照已独立保存）
- 删除后该题库会从启用列表移除

## 4. 考试规则导入导出

「题库管理」→ **考试规则**标签页

| 操作 | 说明 |
|---|---|
| 导入考试规则 | 先校验后应用；校验失败时现有有效规则保持不变 |
| 导出当前规则 | 导出当前启用规则的 JSON 原文 |
| 恢复内置规则 | 写回内置规则并切换为启用状态 |
| 设为启用 | 在「本地规则配置记录」表中切换启用项（支持同时保存多套规则） |

导入成功后，界面会展示规则版本、考试场次与提示项（例如「开启了倒扣分但未设置默认倒扣分值」）。

## 5. 个人数据导出

「我的档案」页面 → **导出个人数据**

导出文件为可读 JSON，包含：

```json
{
  "exportVersion": "1.0.0",
  "exportedAt": "2026-10-14T02:30:00.000Z",
  "profile": { "displayName": "…", "candidateNumber": "…", "…": "…" },
  "certificates": [],
  "attempts": [],
  "settings": [],
  "auditEvents": [],
  "dataSummary": {
    "bankCount": 3,
    "bankIds": ["demo-basic", "demo-intermediate", "demo-advanced"],
    "rulesCount": 1,
    "activeRulesId": "rules-default"
  }
}
```

**注意**：`attempts` 中的每条记录都包含完整**试卷快照**（题目内容、选项顺序、正确答案、分值、规则版本），
因此导出文件可以离线复核每一场考试的判分依据。

> 导出文件**不包含题库正文**（题库有独立的导出入口），只给出元信息摘要。

## 6. 重置与清除

两个操作语义不同，请勿混淆：

| 操作 | 位置 | 影响范围 | 是否可恢复 |
|---|---|---|---|
| **重置考试档案** | 我的档案 | 清除全部考试记录与证件，重新生成考生编号；保留昵称与头像 | ❌ |
| **清除全部本地数据** | 题库管理 → 数据管理 | 删除整个 IndexedDB（档案、记录、证件、题库、规则、设置、历史） | ❌ |

两者都需要：

1. 二次确认对话框
2. 输入指定确认文本（`重置档案` / `清除数据`）

清除本地数据后页面会重新加载，并重新写入内置题库与内置考试规则。

> **建议在重置前先导出个人数据作为备份。**

## 7. 备份与迁移

由于没有后端，跨设备迁移只能通过文件：

1. **导出个人数据**（`iuqa-profile-<日期>.json`）
2. 在新设备上重新建立档案并参加考试（**目前不支持导入个人数据恢复考试记录**，见下方限制）
3. 如使用过自定义题库，逐个**导出题库 JSON**，在新设备上导入

> ⚠️ 目前**没有实现个人数据的反向导入**。导出的 JSON 用于离线查阅与备份留存，
> 不能直接恢复考试记录与证件。这是已知限制，详见 [已知限制](已知限制.md)。

## 8. 错误提示对照表

| 提示 | 含义 | 处理办法 |
|---|---|---|
| 题库文件不是合法的 JSON 文本 | `JSON.parse` 失败 | 检查是否包含注释、尾随逗号或 BOM 字符 |
| 题库未通过校验，当前正在使用的题库保持不变 | Zod 校验失败 | 按错误列表中的字段路径逐项修正 |
| 不支持的题库结构版本，当前支持：1.0.0 | `schemaVersion` 不匹配 | 修改 `schemaVersion` 为 `1.0.0` |
| 题库写入本地数据库失败 | IndexedDB 写入异常 | 检查浏览器是否允许本站点使用本地存储、是否超出配额 |
| 指定的题库不存在，无法导出 | 题库已被删除 | 刷新题库列表后重试 |
| 考试规则未通过校验，现有有效规则保持不变 | 规则校验失败 | 检查及格线是否高于满分、配额合计是否等于题量 |
| 本地数据库初始化失败 | IndexedDB 不可用 | 改用普通窗口（非无痕模式），或清除站点数据后重载 |
| 当前浏览器不支持文件下载功能 | 缺少 `URL.createObjectURL` | 改用最新版 Chrome / Edge / Firefox / Safari |
| 复制到剪贴板失败 | 非安全上下文或权限被拒 | 手动选中文本后使用系统复制快捷键 |

## 9. 数据安全边界（务必阅读）

本系统是**纯前端应用**，导入导出功能**不构成任何安全边界**：

- 使用者可以绕过管理页面，直接用浏览器开发者工具修改 IndexedDB 中的数据。
- 使用者可以修改前端代码、替换题库文件、伪造证件记录。
- 因此**本机保存的成绩与证件记录不具备可被第三方信任的性质**，
  仅适用于演示、教学与个人练习。

题库管理页面的「本地管理模式」开关只是**界面便利功能**，不提供任何真实权限控制。
