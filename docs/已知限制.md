# 已知限制

本文档如实列出本项目**做不到的事情**与**已知的不足**。
凡未在本文档中声明的能力，均不应假定存在。

---

## 一、性质限制（最重要）

### 1. 全部等级、证件与权限均为虚构设定

IUQA 是虚构机构。本项目中的等级名称、证件、印章、签发编号、权限清单**全部为应用内设定**，
不具有现实法律效力，不构成行政许可、职业资格或专业资质，不得用于求职、资质申报或任何需要真实资质的场合。

### 2. 没有真实的网络权限能力

- 本系统**无法、也不会**控制使用者设备的真实网络连接、系统代理设置或对任何真实网站的访问。
- 全部「互联网权限」只影响本站点的模拟页面、徽章、菜单与交互。
- 本系统**不提供**任何 VPN 客户端、服务器地址、配置参数、订阅链接或连接能力，
  也**不提供**任何绕过访问限制的方法、工具或步骤。
- 模拟境外信息专区与 VPN 知识专区的全部内容均为本平台自建的模拟页面与知识说明，
  **不代理、不镜像、不转发**任何真实境外网站的内容。

### 3. 没有在线核验能力

- 本系统**未部署任何验证服务**。
- 证件上的「校验图形」是**装饰性图案，不可扫描**，不含任何可解码数据。
- 证件编号与校验码只在本机具有一致性，第三方**无法通过任何渠道**核验证件真伪。
- 证件页面上的「复制展示页链接」只复制本机应用的页面地址，他人需要在本机打开本应用才能查看。

### 4. 不收集任何个人数据

- 不要求真实身份认证，不收集身份证号码、真实住址、手机号等无必要信息。
- 全部数据仅保存在使用者本机浏览器中，**不产生任何网络请求**（题库、公告、学习材料均随构建产物分发）。
- 学习材料中引用的外部参考资料链接需要使用者主动点击才会离开本站点。

## 二、技术架构限制

### 5. 没有后端，因此没有以下能力

- ❌ 多设备同步
- ❌ 账号体系与登录
- ❌ 云端备份与恢复
- ❌ 多人协作、教师端批阅、排行榜
- ❌ 服务端防作弊（考试全程在客户端完成，理论上可被完全绕过）

### 6. 前端不构成安全边界

- 使用者可以用浏览器开发者工具直接修改 IndexedDB 中的任何数据，包括成绩、证件与权限。
- 使用者可以修改前端代码、替换题库文件、伪造证件记录。
- 「本地管理模式」开关只是界面便利功能，**不是权限边界**。
- 因此本机记录**不具备可被第三方信任的性质**。

### 7. 数据易丢失

- 清除浏览器数据、更换浏览器、使用无痕模式都会导致数据**不可恢复**。
- 浏览器存储配额不足时写入会失败（界面会明确提示，不会假装保存成功）。
- **目前不支持个人数据反向导入**：可以导出个人数据 JSON 用于离线查阅，但不能用它恢复考试记录与证件。

### 8. 数据量限制

- 全部题库随构建产物打包进主 JS 包，当前 3 个题库共 194 题、约 330 KB。
  若题库规模大幅增长，需要改为按需加载（`import.meta.glob` 改为非 eager 模式）。
- 单个头像文件限制 2 MB（超出会导致 IndexedDB 写入缓慢）。

## 三、功能范围限制

### 9. 已实现但有限制的功能

| 功能 | 限制 |
|---|---|
| 模拟讨论区 | 内容仅存在于当前页面会话中，**刷新后重置**，不写入数据库 |
| 模拟发布台 | 「素材附件」只生成演示文件名，**不会读取或上传任何真实文件** |
| 图片导出（PNG） | 依赖 `html-to-image`，极少数浏览器可能因安全策略失败；失败时给出提示并建议改用浏览器打印 |
| PDF 保存 | 通过浏览器打印对话框的「另存为 PDF」实现，**不额外生成 PDF 文件** |
| 补考间隔 | 以本机时间为准，修改系统时间可以绕过 |
| 随机抽题 | 使用可复现的伪随机数（xmur3 + mulberry32），**不是密码学安全随机** |
| 等级晋升 | 只依据本机证件与考试记录判定，数据可被手工修改 |

### 10. 未实现的功能

- ❌ 个人数据反向导入（恢复考试记录与证件）
- ❌ 考试记录的分页（当前一次性载入，记录数极大时可能变慢）
- ❌ 题库的可视化编辑器（只支持 JSON 导入导出）
- ❌ 证件批量导出（一次只能导出一张）
- ❌ 深色主题下的证件打印优化（打印样式按浅色纸张设计）
- ❌ 多语言界面（当前仅中文）

## 四、内容限制

### 11. 示例题库规模有限

- 内置 3 个题库共 **194 道题**，用于演示完整的抽题、判分与证件流程。
- 由于题库规模有限，**同一场考试多次参加时可能出现重复题目**（题目顺序与选项顺序会重新随机化）。
- 题库内容为演示性质，**不构成任何形式的知识权威或专业建议**。

### 12. 模拟专区内容为虚构素材

模拟浏览专区、模拟讨论区、跨域信息专区的机构名称、账号名称、事件与数据
**全部由本平台编写或虚构**，不对应任何真实主体、真实报道或真实事件。

### 13. 考试参数为演示值

默认的题量、时限与及格线（L1 10 题 10 分钟 60 分 → L6 40 题 45 分钟 90 分）
为演示用默认值，全部可通过 `src/data/exam-rules.json` 调整。

## 五、浏览器兼容性

| 浏览器 | 状态 |
|---|---|
| Chrome / Edge（近两年版本） | ✅ 完整支持 |
| Firefox（近两年版本） | ✅ 完整支持 |
| Safari 16+ | ✅ 支持；PNG 导出在部分版本上可能较慢 |
| 移动端 Safari / Chrome | ✅ 支持；PNG 导出与打印行为受系统限制 |
| IE 及旧版 Edge | ❌ 不支持（依赖 IndexedDB v2、ES2022 语法、CSS 嵌套与 `color-mix`） |
| 无痕 / 隐私模式 | ⚠️ 可用，但关闭窗口后数据立即丢失 |

### 依赖的浏览器能力

- IndexedDB（必需，不可用时应用会展示明确错误而不是假装保存成功）
- `crypto.getRandomValues` / `crypto.randomUUID`（缺失时降级到 `Math.random`）
- `URL.createObjectURL`（缺失时下载功能给出明确错误）
- `navigator.clipboard`（缺失时降级到 `document.execCommand('copy')`）
- `window.print`（缺失时给出明确错误）
- `color-mix()` 与 CSS 嵌套（现代浏览器均支持）

## 六、无障碍现状

### 已实现

- 全部交互元素支持键盘操作，答题页额外提供快捷键（← / → 切换题目，1-9 选择选项，F 标记疑问）
- 焦点顺序合理，`:focus-visible` 样式清晰
- 状态不只依赖颜色（徽章带文字、图标与文字双通道）
- 表单错误通过 `aria-describedby` 关联，`role="alert"` 即时播报
- 尊重 `prefers-reduced-motion`
- 倒计时的每秒变化不做实时播报，只在 10 / 5 / 1 分钟节点播报一次

### 尚未做

- ❌ 未在真实屏幕阅读器（VoiceOver / NVDA / TalkBack）上做完整走查
- ❌ 未做 WCAG 2.1 AA 的逐条对照审计
- ❌ 未提供高对比度主题
- ❌ 未提供字体大小以外的无障碍设置（当前只有「答题界面字号」一项）

## 八、如何使用本项目

**适合：**

- 学习 React 19 + TypeScript 严格模式 + Dexie + Zod + Vitest + Playwright 的完整工程实践
- 参考「配置与代码分离」「统一评分引擎」「幂等与串行化」等设计模式
- 作为前端课程设计、演示项目的起点

**不适合：**

- 任何需要真实资质认证的场景
- 任何需要可信记录、防篡改能力的场景
- 任何需要多用户、多设备、服务端能力的场景
- 作为信息安全或法律合规的参考依据
