# 题库编写指南

本文档说明 IUQA 题库 JSON 的结构、六种题型的写法、全部校验规则与常见错误。
题库文件位于 `src/data/question-banks/`，**新增文件即可自动注册，无需修改任何代码**。

---

## 1. 文件位置与命名

```
src/data/question-banks/
├── demo-basic.json          内置示例：L1 / L2 / L3
├── demo-intermediate.json   内置示例：L4 + 专项认证考试
├── demo-advanced.json       内置示例：L5 / L6
└── _parts/                  大题库的分片源文件（不参与构建）
```

- 只有 `question-banks/` **顶层**的 `.json` 文件会被载入；`_parts/` 等子目录会被忽略。
- 文件名不参与业务逻辑，题库身份由文件内的 `bankId` 决定。

---

## 2. 顶层结构

```json
{
  "schemaVersion": "1.0.0",
  "bankId": "my-bank",
  "title": "我的题库",
  "description": "题库说明",
  "language": "zh-CN",
  "version": "1.0.0",
  "author": "题库作者",
  "updatedAt": "2026-10-14",
  "questions": []
}
```

| 字段 | 必填 | 规则 |
|---|---|---|
| `schemaVersion` | ✅ | 当前仅支持 `1.0.0`，其他版本会被拒绝并提示支持范围 |
| `bankId` | ✅ | 唯一标识，仅允许字母、数字、下划线、连字符，最长 64 |
| `title` | ✅ | 题库标题，管理页面展示 |
| `description` | ❌ | 缺省为空字符串 |
| `language` | ❌ | 缺省 `zh-CN` |
| `version` | ✅ | 题库内容版本，会写入试卷快照 |
| `author` / `updatedAt` | ❌ | 元信息 |
| `questions` | ✅ | 题目数组，至少 1 题 |

## 3. 题目通用字段

```json
{
  "id": "MY-001",
  "type": "single_choice",
  "category": "information_literacy",
  "difficulty": 2,
  "tags": ["source-checking", "critical-thinking"],
  "stem": "题干文字",
  "material": "材料正文（部分题型必填）",
  "materialTitle": "材料标题",
  "options": [{ "id": "A", "text": "选项正文" }],
  "answer": { "mode": "key", "correctOptionIds": ["B"] },
  "selection": "single",
  "explanation": "答案解析",
  "score": 5,
  "knowledgePoints": ["来源核验"],
  "source": "题目出处",
  "shuffleOptions": true,
  "scoring": { "mode": "strict", "negativeScore": 0 },
  "multipleValidViewpoints": false
}
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | ✅ | 题库内唯一，最长 64 |
| `type` | ✅ | 见下方题型表 |
| `category` | ✅ | `platform_rules` / `internet_etiquette` / `information_literacy` / `cyber_security` / `logical_reasoning` / `public_discourse` / `digital_wellbeing` |
| `difficulty` | ✅ | 整数 1-5（1 入门，5 专家） |
| `tags` | ❌ | 字符串数组，缺省 `[]`；用于 `requiredTags` / `excludedTags` 过滤 |
| `stem` | ✅ | 题干 |
| `material` / `materialTitle` | 视题型 | `reading_comprehension` 与 `scenario_analysis` **必须提供 `material`** |
| `options` | 视题型 | 除判断题外必须提供至少 2 个；判断题可省略（自动补齐「正确 / 错误」） |
| `answer` | ✅ | 见下方答案模式 |
| `selection` | ❌ | `single` / `multiple`，省略时按题型推导 |
| `explanation` | ✅ | 答案解析，必须说明**为什么** |
| `score` | ✅ | 正数，该题满分 |
| `knowledgePoints` | ❌ | 字符串数组，成绩页展示为复习标签 |
| `shuffleOptions` | ❌ | 是否随机化本题选项顺序，缺省跟随考试规则 |
| `scoring` | ❌ | 题目级评分配置，见下方 |
| `multipleValidViewpoints` | ❌ | 观点辨析题标注「存在多种可辩护立场」 |

---

## 4. 三种答案模式

### 4.1 `key`（键值型）——单选 / 多选 / 阅读 / 观点

```json
"answer": { "mode": "key", "correctOptionIds": ["B"] }
```

- `selection: "single"` 时 `correctOptionIds` 长度**必须为 1**
- `selection: "multiple"` 时长度**必须 ≥ 1**
- 所有 ID 必须引用**已存在的选项**

### 4.2 `boolean`（布尔型）——仅判断题

```json
"answer": { "mode": "boolean", "correctBoolean": true }
```

- 只允许用于 `true_false`
- 归一化时映射为 `TRUE` / `FALSE` 两个选项
- 判断题也可以自定义选项文案，但选项 ID **必须恰好是 `TRUE` 与 `FALSE`**

### 4.3 `points`（分值型）——情景分析题

```json
"answer": {
  "mode": "points",
  "bestOptionIds": ["B"],
  "optionPoints": { "A": 0, "B": 5, "C": 2, "D": -1 }
}
```

- `optionPoints` 必须**恰好覆盖全部选项 ID**（多一个或少一个都会报错）
- `bestOptionIds` 必须引用存在的选项，用于成绩页展示「参考最优选项」
- 判分时累加所选选项的分值，按题目 `score` 截断，默认不低于 0
- 建议让**最高分值等于 `score`**，否则会产生提示性警告

## 5. 六种题型

| `type` | 中文名 | 选项 | 答案模式 | 特殊要求 |
|---|---|---|---|---|
| `single_choice` | 单选题 | 必需 | `key`（长度 1） | 建议 4 个选项 |
| `multiple_choice` | 多选题 | 必需 | `key`（长度 ≥ 1） | 建议 2-3 个正确选项 |
| `true_false` | 判断题 | 可省略 | `boolean` 或 `key` | 题干须为可判定真假的陈述句 |
| `scenario_analysis` | 情景分析题 | 必需 | `points` | **必须提供 `material`** |
| `reading_comprehension` | 阅读理解题 | 必需 | `key` | **必须提供 `material`** |
| `opinion_analysis` | 观点辨析题 | 必需 | `key` | 建议标注 `multipleValidViewpoints` |

### 5.1 单选题

```json
{
  "id": "BASIC-001",
  "type": "single_choice",
  "category": "information_literacy",
  "difficulty": 1,
  "tags": ["source-checking"],
  "stem": "看到一条声称某项重大事件已经发生的网络消息，最合理的做法是什么？",
  "options": [
    { "id": "A", "text": "只要转发量很高，就可以认定为真实" },
    { "id": "B", "text": "核验原始来源，并寻找多个独立可靠来源" },
    { "id": "C", "text": "只看标题就立即转发" },
    { "id": "D", "text": "只要符合自己的预期，就不需要核验" }
  ],
  "answer": { "mode": "key", "correctOptionIds": ["B"] },
  "selection": "single",
  "explanation": "传播量、情绪强度和个人预期都不能代替事实核验。应检查原始来源、发布时间、证据以及独立来源之间是否相互印证。",
  "score": 5,
  "knowledgePoints": ["来源核验", "独立来源判定"]
}
```

### 5.2 多选题

```json
{
  "id": "ADV-001",
  "type": "multiple_choice",
  "category": "cyber_security",
  "difficulty": 4,
  "tags": ["least-privilege"],
  "stem": "下列哪些做法符合权限最小化原则？",
  "options": [
    { "id": "A", "text": "按岗位职责授予完成任务所必需的最小权限" },
    { "id": "B", "text": "为方便协作，默认所有人拥有编辑权限" },
    { "id": "C", "text": "对高敏感资料设置单独授权并记录访问日志" },
    { "id": "D", "text": "权限一次授予后长期不再复核" }
  ],
  "answer": { "mode": "key", "correctOptionIds": ["A", "C"] },
  "selection": "multiple",
  "explanation": "权限最小化要求权限范围与任务需求匹配，并对高敏感资源单独授权、保留可追溯记录。",
  "score": 5,
  "knowledgePoints": ["权限最小化", "访问日志"]
}
```

**判分规则**：默认采用**严格匹配**——选项集合完全一致才得满分，少选、多选、错选均不得分。

**部分得分**需要两处同时声明：

```json
"scoring": {
  "mode": "partial",
  "partial": { "strategy": "per_option", "penaltyPerWrongOption": 1 }
}
```

同时考试规则的 `scoring.partialCreditEnabled` 必须为 `true`，否则题目声明会被降级为严格匹配。
**不允许题目私自改变全卷规则。**

- `strategy: "per_option"`：每个正确选项均分该题分值，再扣错选罚分
- `strategy: "proportional"`：按「选对比例 − 选错比例」计分

### 5.3 判断题

```json
{
  "id": "BASIC-010",
  "type": "true_false",
  "category": "platform_rules",
  "difficulty": 1,
  "tags": ["privacy"],
  "stem": "本平台会收集考生的身份证号码用于身份认证。",
  "answer": { "mode": "boolean", "correctBoolean": false },
  "selection": "single",
  "explanation": "本平台不要求真实身份认证，只收集昵称与可选头像，且全部数据仅保存在本机。",
  "score": 5,
  "knowledgePoints": ["数据最小化"]
}
```

### 5.4 情景分析题

```json
{
  "id": "INT-030",
  "type": "scenario_analysis",
  "category": "public_discourse",
  "difficulty": 3,
  "tags": ["discussion"],
  "materialTitle": "情景：讨论中出现未经核实的指控",
  "material": "在一次模拟讨论中，某位参与者发布了一条针对特定群体的指控，但未提供任何来源。讨论随即升温，多人开始转发该说法。",
  "stem": "作为讨论参与者，最合适的处理方式是什么？",
  "options": [
    { "id": "A", "text": "立即转发，让更多人看到", "points": 0, "rationale": "未核验即转发会放大未经证实的信息。" },
    { "id": "B", "text": "要求发布者提供来源，并说明在来源缺失时无法采信该说法", "points": 5, "rationale": "把举证责任放回提出者，同时保留讨论空间。" },
    { "id": "C", "text": "直接对该参与者进行人身攻击", "points": -1, "rationale": "人身攻击使讨论无法继续，也转移了议题。" },
    { "id": "D", "text": "保持沉默，等其他人处理", "points": 2, "rationale": "避免扩大影响，但未推动讨论回到证据层面。" }
  ],
  "answer": {
    "mode": "points",
    "bestOptionIds": ["B"],
    "optionPoints": { "A": 0, "B": 5, "C": -1, "D": 2 }
  },
  "selection": "single",
  "explanation": "处理未经核实的指控时，应把举证责任放回提出者，并明确指出在来源缺失的情况下无法采信。人身攻击与沉默都没有推动讨论回到证据层面。",
  "score": 5,
  "knowledgePoints": ["举证责任", "讨论规范"]
}
```

> `optionPoints` 与各选项的 `points` 必须一致。两者都存在是为了让分值既可就近阅读，也可被引擎直接读取。

### 5.5 阅读理解题

```json
{
  "id": "INT-010",
  "type": "reading_comprehension",
  "category": "information_literacy",
  "difficulty": 3,
  "tags": ["statistics"],
  "materialTitle": "材料：两份口径不同的统计报告",
  "material": "甲报告称某项服务的使用率较去年增长 12%，乙报告称同期下降 3%。两份报告都注明数据来自公开问卷，但甲报告的样本包含重复提交，乙报告剔除了未完成问卷的样本。",
  "stem": "根据材料，两份报告结论相反最可能的原因是？",
  "options": [
    { "id": "A", "text": "其中一份报告存在造假" },
    { "id": "B", "text": "两份报告的统计口径与样本范围不同" },
    { "id": "C", "text": "问卷数据永远不可信" },
    { "id": "D", "text": "增长率无法被计算" }
  ],
  "answer": { "mode": "key", "correctOptionIds": ["B"] },
  "selection": "single",
  "explanation": "结论冲突首先应检查口径差异：样本范围、去重规则与完成度处理不同都会导致方向相反的结论。在排除口径差异之前，直接指控造假属于跳跃推论。",
  "score": 5,
  "knowledgePoints": ["统计口径", "样本偏差"]
}
```

### 5.6 观点辨析题

```json
{
  "id": "ADV-040",
  "type": "opinion_analysis",
  "category": "logical_reasoning",
  "difficulty": 4,
  "tags": ["argument-analysis"],
  "stem": "某观点称「因为这项技术在多个地区被限制，所以它一定有害」。下列哪项对该论证的批评最准确？",
  "options": [
    { "id": "A", "text": "该论证用「被限制」直接推出「有害」，缺少中间的证据环节" },
    { "id": "B", "text": "该论证的结论与我的立场不同，因此是错误的" },
    { "id": "C", "text": "该论证使用了统计数据，因此不可信" },
    { "id": "D", "text": "该论证没有引用专家意见，因此无效" }
  ],
  "answer": { "mode": "key", "correctOptionIds": ["A"] },
  "selection": "single",
  "multipleValidViewpoints": true,
  "explanation": "本题不评判立场，只评判论证方式。该论证从「被限制」直接跳到「有害」，缺失了限制原因、证据与因果关系的中间环节。其余选项都以立场或形式理由代替了对论证结构的分析。",
  "score": 5,
  "knowledgePoints": ["因果跳跃", "论证结构分析"]
}
```

> **观点辨析题的考查重点必须是**证据辨识、逻辑一致性、因果关系与来源核验，
> **不得**因为使用者持有某种政治观点而判定其不合格。

## 6. 全部校验规则

导入时系统会依次校验以下内容，任何一条不通过都会**拒绝导入并给出字段路径**：

### 结构层

- JSON 是否能够解析
- `schemaVersion` 是否受支持
- 必填字段是否缺失、字段类型是否正确
- `type` / `category` / `difficulty` 是否为合法枚举值

### 关系层

- 题目 ID 是否重复（定位到 `questions[i].id`）
- 选项 ID 是否重复
- 正确答案是否引用了**存在的**选项
- 单选题是否**恰好一个**正确答案
- 多选题是否**至少一个**正确答案
- `boolean` 答案是否只用于判断题
- 判断题是否误用了 `points` 答案
- 情景分析题的 `optionPoints` 是否覆盖全部选项
- `optionPoints` 是否引用了不存在的选项
- `bestOptionIds` 是否引用了存在的选项
- 声明 `partial` 时是否提供了 `partial` 规则
- 材料题是否提供了 `material`
- 选项数量是否少于 2

### 全局层

- 题库总分是否大于 0
- 题目数量是否满足考试要求（开考时判定，不足则**考试无法启动**）

### 提示性警告（不阻断导入）

- 情景分析题单选项最高分值与题目分值不一致
- 题目分值不是整数
- 题目未设置标签
- 题库题目少于 10 道

错误路径示例：

```
questions[3].answer.correctOptionIds[0]：正确答案引用了不存在的选项 ID：Z
questions[7].answer.optionPoints.C：选项 C（第 3 个）缺少分值定义
questions[2].id：题目 ID 重复：BASIC-003
```

## 7. 大题库的分片装配

题库较大时，逐条写入单个 JSON 容易在编辑过程中出错。推荐拆分为多个片段文件后用脚本装配：

```bash
mkdir -p src/data/question-banks/_parts/my-bank

# meta.json 提供顶层字段
cat > src/data/question-banks/_parts/my-bank/meta.json <<'JSON'
{
  "schemaVersion": "1.0.0",
  "bankId": "my-bank",
  "title": "我的题库",
  "description": "分片装配示例",
  "language": "zh-CN",
  "version": "1.0.0"
}
JSON

# 01.json / 02.json … 各自是题目对象数组
node scripts/assemble-bank.mjs \
  --meta  src/data/question-banks/_parts/my-bank/meta.json \
  --parts src/data/question-banks/_parts/my-bank \
  --out   src/data/question-banks/my-bank.json
```

脚本会按文件名排序合并片段，并打印题目总数与分类 / 题型分布。

## 8. 校验你的题库

修改题库后运行：

```bash
pnpm test -- tests/unit/data/question-bank-files.test.ts
```

该测试会：

1. 校验 `question-banks/` 下的**每一个**题库文件
2. 检查每个题库的题目分值是否为正数、ID 是否唯一
3. 检查每场考试引用的题库是否存在
4. 检查每场考试的**题目数量与分类配额是否都能被题库满足**

第 4 项是最容易忽略的一条：即使题库本身合法，如果某场考试的配额（例如「网络安全 8 道」）
无法被满足，**该场考试将无法启动**，并在考前须知页给出缺口清单。

## 9. 编写建议

1. **每个选项都要是合理的干扰项**，不要写明显凑数的选项。
2. **解析必须说明「为什么」**，不能只重复答案。
3. **避免真实政治人物、真实政治争议、真实国家/地区立场、真实企业负面指控**；
   举例请使用虚构或通用场景（「某平台」「甲机构/乙机构」「某条群聊消息」）。
4. **观点辨析题只考论证方式**，并在解析中写明「本题不评判立场」。
5. **情景分析题的每个选项都要写 `rationale`**，说明该做法的后果。
6. **分值建议统一**（内置题库统一使用 5 分），这样试卷原始满分易于预期；
   评分引擎会自动做百分制归一化，不必强求题目分值合计等于 100。
7. **标签要有区分度**，便于按主题抽题。
8. 涉及跨境访问与 VPN 的题目，**只考原理、风险类型与合规边界**，
   不得提供任何绕过访问限制的方法、工具、配置或步骤。
